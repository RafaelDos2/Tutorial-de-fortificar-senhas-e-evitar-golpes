O que é uma Passphrase (Frase-Chave)?

Uma Passphrase é uma sequência de palavras aleatórias combinadas. Elas costumam ser muito mais seguras do que senhas curtas cheias de caracteres aleatórios e difíceis de lembrar.

Difícil de Lembrar / Curta: X$9#mK2!pL 10 caracteres (Médio risco de esquecimento)
Fácil de Lembrar / Ultra Segura: cavalo-piano-cometa-girassol-88 29 caracteres (Leva séculos para ser quebrada)

Dicas para Criar Frases-Chave:

  • Combine 4 ou mais palavras sem relação lógica direta.
  • Separe as palavras com hífen (-), espaço ou pontos.
  • Adicione pelo menos um número ou símbolo especial para reforço.
  • Nunca use citações populares, músicas ou provérbios famosos.

O que é Múltiplo Fator (2FA)?

Mesmo que um cibercriminoso descubra sua senha, o 2FA/MFA exige uma segunda confirmação (código via aplicativo como Google/Microsoft Authenticator) no seu celular para autorizar o acesso.
